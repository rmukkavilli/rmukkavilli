### 🚀 Featured Projects

#### [`api-reliability-agent`](https://github.com/rmukkavilli/api-reliability-agent)

Read-only agentic reliability system built with Python, the OpenAI Agents SDK, Gemini, `httpx`, and FastAPI.

* Orchestrates function tools to inspect health, patient, and screening endpoints
* Uses asynchronous HTTP requests and deterministic HTTP/JSON contract validation
* Generates evidence-based API reliability reports
* Enforces URL validation, exception handling, and read-only safety constraints
* Prevents unsupported verification claims when an endpoint cannot be confirmed

#### [`clinical-screening-api`](https://github.com/rmukkavilli/clinical-screening-api)

Production-style clinical screening backend built with Python, FastAPI, PostgreSQL, SQLAlchemy, Alembic, Docker, and PyTest.

* Provides patient, screening, and health-check APIs
* Implements persistent PostgreSQL storage and database migrations
* Includes automated API tests and deployment configuration
* Deployed publicly on Render

📖 [Live API Documentation](https://backend-project-api-cswq.onrender.com/docs)

#### [`pytest-fhir`](https://github.com/rmukkavilli/pytest-fhir)

Reusable Python/PyTest framework for FHIR API integration and reliability testing.

* Provides reusable API clients, fixtures, and dependency injection
* Supports bearer-token authentication and environment-based configuration
* Refreshes authentication once for `401` responses
* Avoids retrying deterministic `4xx` failures
* Applies bounded retries for transient `5xx` failures
* Runs automated tests through GitHub Actions
